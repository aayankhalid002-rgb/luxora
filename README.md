# LUXORA — Premium E-Commerce Frontend Demo

A polished, responsive e-commerce storefront concept built with semantic HTML, CSS and vanilla JavaScript. This is a frontend-only portfolio/demo project.

## Run locally
1. Extract the ZIP archive.
2. Open the `LUXORA` folder.
3. Double-click `index.html` to launch it in a modern browser.

No build tools, package installation, backend or database are required.

## Included features
- Responsive home page and desktop/mobile navigation
- 24 sample products across six categories
- Product detail pages
- Product search, category filtering, price filtering and sorting
- Shopping bag with quantity controls, remove action and automatic totals
- Wishlist with persistent browser storage
- Validated demo checkout and order confirmation
- Local demo order history
- Contact and newsletter form validation/demo feedback
- FAQ accordion
- `localStorage` persistence for cart, wishlist and demo orders

## Important demo limitations
This project does not include a backend, database, user accounts, real payment processing, email delivery, inventory synchronization, shipping integration or live order management. Checkout creates a demo order in the current browser only. Contact and newsletter forms do not send data to a business. Product names, prices, ratings and product imagery are sample content.

## External assets
Product photography and web fonts are loaded from Unsplash and Google Fonts. An internet connection is needed for those external assets; the layout and JavaScript interactions are local. A fallback image is shown if a product image cannot load.
